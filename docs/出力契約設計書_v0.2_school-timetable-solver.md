## 1. 目的

本設計書は、`school-timetable-solver`が生成するExcel時間割の出力契約を定義する。

本システムの計算結果を単純な一覧形式で出力するのではなく、日付ごとに以下の情報を持つ時間割マトリクスとして出力する。

- 日付
- 曜日
- 校舎
- 教室
- 1限から6限
- クラス
- 教科
- 担当教師
- 教師休み注記

出力形式は、参照資料である`出力例.xlsx`の通常日付ブロックを基準とする。

## 5. 出力対象日

### 5.1 採用範囲

出力対象日は入力Excelで決定する。

出力処理は、入力Excelから渡された出力対象日を追加・削除してはならない。

### 5.2 並び順

出力対象日は日付の昇順に並べる。

同一日付が複数定義されている場合は入力エラーとし、出力処理を開始しない。

### 5.3 休館日・特別日

休館日、特別日、授業配置禁止日であっても、入力Excel上で出力対象日として定義されている場合は日付マトリクスを生成する。

ただし、本バージョンでは以下の文字を表示しない。

- 休館
- 終業式
- 特別講座
- お盆休み
- その他のカレンダー種別または備考

授業が存在しない教室・時限セルは空欄とする。

### 5.4 授業配置可能範囲

授業を配置できる日および時限は入力Excelで定義する。

出力処理は配置可否を再計算せず、確定した時間割結果を表示する。

## 6. 日付マトリクスの配置

### 6.1 配置方向

日付マトリクスは、1行に2日分を配置し、左から右、上から下の順に追加する。

```text
1日目  2日目
3日目  4日目
5日目  6日目
7日目  8日目
...
```

4日単位のまとまりは論理上のグループであり、物理配置は2列の行優先配置とする。

### 6.2 配置計算

出力対象日の0始まりの順序番号を`date_index`とする。

```text
pair_index = date_index // 2
side_index = date_index % 2
```

| `side_index` | 配置 |
|---:|---|
| 0 | 左 |
| 1 | 右 |

### 6.3 開始位置

参照資料に合わせ、最初の日付マトリクスはWorksheetの左上側へ配置する。

```text
最初の左側マトリクス開始セル: A2
```

1行目は空白とする。

### 6.4 水平方向の間隔

左右の日付マトリクスの間には空白列を1列設ける。

```text
左マトリクス
空白1列
右マトリクス
```

### 6.5 垂直方向の間隔

上下の日付マトリクスの間には2行設ける。

| 行 | 用途 |
|---|---|
| 1行目 | 教師休み注記 |
| 2行目 | 空白 |

教師休み注記行にはセル結合および罫線設定を行わない。
教師休み注記行のフォント、文字サイズおよび行高は時間割本体と同じ標準書式を使用し、教師休み専用の上書きを行わない。
2行目には値の書き込み、セル結合および罫線設定を行わない。

## 7. 日付マトリクスの寸法

### 7.1 列数

全有効教室数を`room_count`とする。

```text
matrix_width = 2 + room_count
```

| 列 | 内容 |
|---:|---|
| 1 | 日付、曜日、時限 |
| 2 | 日付、曜日、項目名 |
| 3以降 | 教室 |

校舎数、教室数、校舎順、教室順および最大数は入力Excelで決定する。

左右の日付マトリクスは同じ校舎・教室構成を使用する。

### 7.2 行数

1日分の時間割本体は20行、教師休み注記はその直下1行とする。

```text
ヘッダ         2行
6時限 × 3行  18行
----------------
合計          20行
```

上下配置の行間2行を加えた垂直方向の配置間隔は22行とする。

```text
matrix_row_stride = 22
```

### 7.3 開始座標

左側マトリクスの開始列番号を`1`、最初の開始行番号を`2`とする。

```text
matrix_width = 2 + room_count
horizontal_gap = 1
matrix_row_stride = 22

start_row = 2 + (date_index // 2) * matrix_row_stride

start_column =
    1                                      when side_index = 0
    1 + matrix_width + horizontal_gap      when side_index = 1
```

右側マトリクスの開始列は、教室数に応じて動的に決定する。

固定セル番地へ依存してはならない。

## 9. 1日分の列構造

日付マトリクスの開始列を`C`とする。

| 相対列 | 内容 |
|---:|---|
| `C + 0` | 日付、曜日、時限番号および時刻 |
| `C + 1` | 日付、曜日、クラス・教科・担当 |
| `C + 2`以降 | 入力Excelの順序に従う教室列 |

教室列は、校舎単位で連続していなければならない。

同一校舎内の教室も入力Excelで定義された順序に従う。

## 10. セル値

### 10.1 日付

日付はExcelの日付型として書き込む。

表示形式は参照資料と同じ以下の形式とする。

```text
M月D日
```

表示例：

```text
7月18日
```

Excelの数値書式は次を使用する。

```text
m"月"d"日"
```

参照資料に存在する外部Workbook参照式は使用しない。

日付値を直接セルへ書き込む。

### 10.2 曜日

曜日は日本語の文字列として直接書き込む。

| 曜日番号 | 出力値 |
|---:|---|
| 0 | 月曜日 |
| 1 | 火曜日 |
| 2 | 水曜日 |
| 3 | 木曜日 |
| 4 | 金曜日 |
| 5 | 土曜日 |
| 6 | 日曜日 |

曜日は日付から計算する。

入力Excelから曜日文字列を受け取らない。

### 10.3 校舎

校舎ヘッダには入力Excelで定義された校舎表示名を出力する。

内部IDを表示してはならない。

### 10.4 教室

教室ヘッダには入力Excelで定義された教室表示名を出力する。

内部IDを表示してはならない。

### 10.5 項目名

各時限について、項目名列へ以下を固定値として出力する。

```text
クラス
教科
担当
```

### 10.6 時限番号

時限番号は以下の丸数字で表示する。

| 時限番号 | 表示 |
|---:|---|
| 1 | ① |
| 2 | ② |
| 3 | ③ |
| 4 | ④ |
| 5 | ⑤ |
| 6 | ⑥ |

### 10.7 時限の開始・終了時刻

時限番号の下へ、入力Excelで定義された開始時刻と終了時刻を表示する。

同一セル内で改行する。

```text
①
9:30～11:05
```

出力文字列の形式は以下とする。

```text
{丸数字}
{開始時刻}～{終了時刻}
```

時刻はコードへ固定しない。

### 10.8 授業情報

各授業は、該当する日付、時限、教室の3セルへ表示する。

| 行 | 出力値 |
|---|---|
| クラス行 | クラス表示名 |
| 教科行 | 教科表示名 |
| 担当行 | 教師表示名 |

内部IDは表示しない。

授業が存在しない場合は空文字列を出力するか、セル値を設定しない。

### 10.9 教師休み注記

入力Excelの`10_教師休み`と、`15_教師休日日数ルール`からSolverが選択した終日休みを、日付ごとに`R + 20`へ出力する。

- 教師の`home_campus_id`に一致する校舎の最初の教室列から、入力行順に隙間なく配置する。
- 終日休みは教師表示名だけを1セルへ出力する。
- 期間別日数ルールから選択した休みは終日休みとして出力する。
- 時限指定休みは教師表示名を1セルへ出力し、その直右セルへ時限表記を出力する。
- 時限指定休みは、教師1名につき2セルを使用する。
- 校舎をまたいで継続してはならない。
- 参照資料にある手作業由来の空きセルおよび`原6空き`形式は再現しない。

時限表記は`03_時限.period_name`を使用する。

- 1時限だけの場合は`①`のように単独で表す。
- 2時限または非連続時限は`①②`、`①⑥`、`①②⑤`のように連結する。
- 3時限以上の連続部分は`①～③`、`③～⑤`のように先頭と末尾を全角波線で結ぶ。
- 3時限以上の連続部分と非連続時限が混在する場合は`①～③⑤`のように連結する。
- 丸付き数字は入力データのUnicode表記を推測せず、時限マスタの表示名へ統一する。

必要セル数が所属校舎の教室列数を超える場合は
`OUTPUT_TEACHER_LEAVE_OVERFLOW`として出力を中止する。

## 11. セル結合

### 11.1 日付セル

日付行の左端2列を横結合する。

```text
開始列CからC+1
```

### 11.2 曜日セル

曜日行の左端2列を横結合する。

```text
開始列CからC+1
```

### 11.3 校舎セル

校舎名は、その校舎に所属する教室数分の列を横結合する。

例：

```text
校舎A
├── 101
├── 102
└── 103
```

この場合、校舎Aのヘッダは3列結合する。

教室数が1の場合はセル結合を行わない。

### 11.4 時限セル

各時限の時限番号・時刻セルは、クラス、教科、担当の3行を縦結合する。

```text
①のセル = ①クラス行から①担当行まで
```

### 11.5 結合しないセル

以下は結合しない。

- 項目名セル
- 教室ヘッダ
- 授業情報セル
- 教師休み注記行
- 空白行
- 未使用枠

## 12. 罫線

### 12.1 使用する線種

参照資料の例外的な罫線は無視し、以下の2種類だけを使用する。

| 契約上の名称 | Excel罫線 | 用途 |
|---|---|---|
| 普通線 | `thin` | 外周、時限境界、校舎境界等 |
| 点線相当 | `hair` | ヘッダ内部、同一校舎内の教室間、時限内部等 |

本設計書における「点線」は、Excelの`dotted`ではなく、参照資料で点線状に見える`hair`を意味する。

### 12.2 横罫線

| 境界 | 線種 |
|---|---|
| 日付マトリクス上端 | 普通線 |
| 日付と曜日の間 | 点線相当 |
| 校舎と教室の間 | 点線相当 |
| 曜日・教室行と①クラス行の間 | 普通線 |
| 各時限のクラスと教科の間 | 点線相当 |
| 各時限の教科と担当の間 | 点線相当 |
| 各時限の担当と次時限のクラスの間 | 普通線 |
| ⑥担当行の下端 | 普通線 |

各時限ブロックは以下の構造になる。

```text
──────────── 普通線
クラス
┈┈┈┈┈┈┈┈┈┈ 点線相当
教科
┈┈┈┈┈┈┈┈┈┈ 点線相当
担当
──────────── 普通線
```

### 12.3 縦罫線

| 境界 | 線種 |
|---|---|
| 日付マトリクス左端 | 普通線 |
| 時限列と項目名列の間 | 点線相当 |
| 項目名列と最初の教室列の間 | 普通線 |
| 同一校舎内の教室間 | 点線相当 |
| 校舎と校舎の境界 | 普通線 |
| 日付マトリクス右端 | 普通線 |

### 12.4 教室×時限マス

各教室×時限のマスは3行で構成する。

- 上端：普通線
- クラスと教科の間：点線相当
- 教科と担当の間：点線相当
- 下端：普通線
- 左右：同一校舎内では点線相当
- 校舎境界またはマトリクス外周では普通線

### 12.5 罫線設定方法

罫線はセル単位で設定する。

隣接する2セルの共有境界に異なる線種を設定してはならない。

罫線設定処理はExcel Adapter内で一元化し、値書き込み処理へ分散させない。

## 13. 未使用枠

出力対象日の件数が偶数でない場合、最終行の右側に未使用枠が生じる。

例：

```text
1日目  2日目
3日目
```

未使用枠には何も生成しない。

- セル値を設定しない
- セル結合しない
- 罫線を設定しない
- 校舎・教室ヘッダを生成しない
- 空の日付マトリクスを生成しない

入力Excelで出力対象日として定義された日付は、授業が存在しない場合でも日付マトリクスを生成する。

未使用枠と、授業が存在しない出力対象日は明確に区別する。

## 14. 出力用データモデル

Excel Adapterへソルバーの内部モデルを直接渡さない。

Excel座標へ依存しない出力用データモデルをServiceで構築する。

推奨モデルを以下に示す。

```python
@dataclass(frozen=True)
class TimetableDocumentModel:
    dates: tuple["DailyTimetableModel", ...]
    campuses: tuple["CampusColumnGroupModel", ...]
    periods: tuple["OutputPeriodModel", ...]


@dataclass(frozen=True)
class DailyTimetableModel:
    target_date: date
    lessons_by_period_and_room: Mapping[
        tuple[int, str],
        "OutputLessonModel",
    ]
    teacher_leaves: tuple["OutputTeacherLeaveModel", ...]


@dataclass(frozen=True)
class OutputTeacherLeaveModel:
    teacher_display_name: str
    campus_id: str
    unavailable_period_ids: tuple[str, ...]


@dataclass(frozen=True)
class CampusColumnGroupModel:
    campus_id: str
    campus_display_name: str
    rooms: tuple["RoomColumnModel", ...]


@dataclass(frozen=True)
class RoomColumnModel:
    room_id: str
    room_display_name: str


@dataclass(frozen=True)
class OutputPeriodModel:
    period_number: int
    start_time: time
    end_time: time


@dataclass(frozen=True)
class OutputLessonModel:
    class_display_name: str
    subject_display_name: str
    teacher_display_name: str
```

実際のクラス名は既存コーディング規約およびモデル構成に合わせて調整できる。

ただし、Excelセル番地、罫線、結合範囲等をService側モデルへ含めてはならない。

## 15. 責務分担

### 15.1 出力用データ構築Service

推奨責務：

- 出力対象日の昇順整列
- 校舎および教室の出力順整理
- 時限情報の出力順整理
- 授業結果の`日付×時限×教室`への展開
- 内部IDから表示名への変換
- 教師休みの所属校舎・表示名・時限順の解決
- 校舎ごとの教師休み注記セル数検証
- 出力前の重複検証
- Excel非依存の`TimetableDocumentModel`生成

推奨公開メソッド：

```python
execute()
```

Serviceは`openpyxl`をimportしてはならない。

### 15.2 Excel出力Adapter

推奨責務：

- Workbook作成
- `全体`Worksheet作成
- 日付マトリクスの開始座標計算
- セル値書き込み
- 日付書式設定
- セル結合
- 普通線および点線相当の設定
- 教師休み注記の左詰め配置および時限表記生成
- 未使用枠を生成しない制御
- `.xlsx`ファイル保存

公開メソッド：

```python
write()
```

Excel固有処理は`adapter/excel_output_adapter.py`またはアーキテクチャ設計書で認められたExcel Adapterへ配置する。

## 16. 入力データへの要求

本出力契約を満たすため、入力契約は以下を保証しなければならない。

| 情報 | 必須条件 |
|---|---|
| 出力対象日 | 重複なし。日付型として解釈可能 |
| 日付ごとの配置可能時限 | ソルバーが判定できること |
| 時限 | 1から6を一意に定義 |
| 開始時刻 | 各時限に必須 |
| 終了時刻 | 各時限に必須 |
| 校舎表示順 | 一意に順序を決定可能 |
| 教室表示順 | 同一校舎内で一意に順序を決定可能 |
| 教室priority | 0以上の整数。数値が大きいほど優先 |
| 教室所属校舎 | 各教室が1校舎に所属 |
| 教師所属校舎 | 各有効教師が有効な`home_campus_id`を持つ |
| 校舎表示名 | 必須 |
| 教室表示名 | 必須 |
| クラス表示名 | 必須 |
| 教科表示名 | 必須。入力契約に従い空文字列による空白セル出力を許容 |
| 教師表示名 | 必須 |

校舎および教室の表示順を、IDの文字列順や名称の辞書順から推測してはならない。

入力契約で明示された順序を使用する。

## 17. 出力前検証

Excel出力前に以下を検証する。

### 17.1 日付

- 出力対象日に重複がない
- 日付昇順へ整列可能
- 授業結果の日付が出力対象日に含まれる

### 17.2 時限

- 時限番号が1から6まで存在する
- 時限番号に重複がない
- 各時限に開始時刻と終了時刻がある
- 開始時刻が終了時刻より前である
- 授業結果の時限が1から6に含まれる

### 17.3 校舎・教室

- 各教室に所属校舎がある
- 各教師休みに所属校舎がある
- 各日付・校舎の教師休み注記が教室列数以内に収まる
- 校舎表示順を一意に決定できる
- 教室表示順を一意に決定できる
- 授業結果の教室が出力対象教室に含まれる

### 17.4 授業

以下の組み合わせは一意でなければならない。

```text
日付 × 時限 × 教室
```

同一組み合わせに複数授業が存在する場合、文字列を連結して出力してはならない。

出力エラーとして処理する。

同一クラス・同一日の全授業は同一教室に出力しなければならない。複数教室への配置は`H15`の出力エラーとする。

同一クラスの授業間に連続2コマ以上の空きがある配置は`H16`の出力エラーとする。空き1コマは許可する。

クラス・教科ごとの授業配置数ルールについて、指定日時範囲内の生成数が厳密値と異なる場合は`H17`の出力エラーとする。入力上の複数セグメントは解決済みの和集合で数え、異なるルールはそれぞれ独立に検査する。

教師ごとの期間別終日休みについて、選択日数が厳密値と異なる場合、または選択日に授業がある場合は`H18`の出力エラーとする。固定休みと選択休みの注記セル数が校舎の教室列数を超える場合は`H19`の出力エラーとする。

同一教室を連続時限で別クラスへ交替する配置は`S10`の警告とし、出力自体は許可する。

同一クラスの最初と最後の授業の間に空き時限がある配置は`S11`の警告とし、出力自体は許可する。

同一クラスの授業が1日に1コマだけの配置は`S12`の警告とし、出力自体は許可する。

同一クラスが連続時限で同じ教科を受ける配置は、隣接ペアごとに`S13`の警告とし、出力自体は許可する。

同一クラス・同一教科が1日に2コマ以上配置される場合は、対象日ごとに`S14`の警告とし、出力自体は許可する。

同一クラス・同一教科が1日に2コマ以上配置され、その翌暦日にも同じ教科が配置される場合は、対象の連続日ごとに`S15`の警告とし、出力自体は許可する。開講日の間に休講日がある場合、次の出力日を翌日とはみなさない。

クラス・教科ごとの実配置累積数が、候補日別の配置可能コマ数に比例させた累積目標から外れる場合は、対象のクラス・教科ごとに`S16`の警告とスコアを出し、出力自体は許可する。スコアは`0`を完全一致、`1000`を正規化上限とする。

入力された授業配置数選好ルールについて、指定日時範囲内の生成数が希望値と異なる場合は、ルールごとに`S17`の警告を出し、出力自体は許可する。警告には希望値、生成数、絶対偏差を含める。

クラスの暦日連続登校がその日ごとの推奨連続登校日数を超える場合は、連続列ごとに`S18`の警告を出し、出力自体は許可する。警告には連続日数、適用された推奨値、累積ペナルティを含める。

校舎内最高priorityより低い教室へ授業が配置された場合は`S19`の警告を出し、出力自体は許可する。警告には教室priority、校舎内最高priority、配置コマ数、合計ペナルティを含める。

### 17.5 表示名

以下の表示名は空文字列であってはならない。

- 校舎
- 教室
- クラス
- 教科
- 教師

## 18. 例外処理

| 条件 | 処理 |
|---|---|
| 出力対象日が0件 | 入力エラー |
| 時限が6件でない | 入力エラー |
| 教室が0件 | 入力エラー |
| 同一の日付×時限×教室に複数授業 | 出力エラー |
| 同一クラス・同一日に複数教室 | 出力エラー |
| 同一クラスの授業間に連続2コマ以上の空き | 出力エラー |
| 授業配置数ルールの指定範囲内生成数が厳密値と不一致 | 出力エラー |
| 教師の期間別休日日数不一致または休み日の授業配置 | 出力エラー |
| 固定・選択休み注記が校舎の教室列数を超過 | 出力エラー |
| 同一教室を連続時限で別クラスへ交替 | 警告として出力を継続 |
| 同一クラスの同日授業間に空き時限 | 警告として出力を継続 |
| 同一クラスの同日授業が1コマだけ | 警告として出力を継続 |
| 同一クラスが連続時限で同じ教科を受講 | 警告として出力を継続 |
| 教師休み注記が所属校舎の列数を超過 | `OUTPUT_TEACHER_LEAVE_OVERFLOW`として出力中止 |
| 授業が未知の教室を参照 | 出力エラー |
| 授業が未知の時限を参照 | 出力エラー |
| 表示名が欠落 | 入力エラー |
| 出力先ファイルを保存できない | I/Oエラー |

一部だけのExcelを成功扱いで残してはならない。

保存処理に失敗した場合は、必要に応じて一時ファイルを削除する。

## 19. 受入条件

### 19.1 Workbook

- `.xlsx`ファイルが生成される
- Worksheetが1つだけ存在する
- Worksheet名が`全体`である
- 外部Workbook参照を含まない

### 19.2 日付配置

- 出力対象日が日付昇順である
- 1日目が左、2日目が右に配置される
- 3日目が次の行の左、4日目が右に配置される
- 以降も同じ規則で配置される
- 左右の間に空白列が1列存在する
- 上下の間に空白行が2行存在する

### 19.3 日付・曜日

- 日付セルが左端2列の結合セルである
- 曜日セルが左端2列の結合セルである
- 日付が`7月18日`形式で表示される
- 曜日が`土曜日`形式で表示される
- 曜日が日付と一致する

### 19.4 校舎・教室

- 校舎順が入力Excelの定義と一致する
- 教室順が入力Excelの定義と一致する
- 校舎セルが所属教室数分だけ結合される
- 左右および全日付で同一の校舎・教室構成になる

### 19.5 時限

- ①から⑥まで表示される
- 開始時刻と終了時刻が入力Excelと一致する
- 時限セルが3行結合される
- 各時限にクラス、教科、担当の3行が存在する

### 19.6 授業

- 授業が日付、時限、教室の正しい交点へ表示される
- クラス、教科、担当がそれぞれ正しい行へ表示される
- 授業がないセルは空欄である
- 休館日等に自動文言が表示されない
- 同一クラス・同一日の授業が同一教室に表示される
- 同一クラスの授業間に連続2コマ以上の空きがない
- 同一クラスの同日授業間に空き時限がある場合もExcel出力を継続する
- 同一クラスの同日授業が1コマだけの場合もExcel出力を継続する
- 同一クラスが連続時限で同じ教科を受ける場合もExcel出力を継続する

### 19.7 セル結合

- 日付セルの結合が正しい
- 曜日セルの結合が正しい
- 校舎セルの結合が正しい
- 時限セルの結合が正しい
- 未使用枠に結合セルがない

### 19.8 罫線

- 使用する線種が`thin`と`hair`の2種類である
- 日付と曜日の間が`hair`である
- 校舎と教室の間が`hair`である
- 時限間が`thin`である
- クラス、教科、担当の内部境界が`hair`である
- 校舎間が`thin`である
- 同一校舎内の教室間が`hair`である
- マトリクス外周が`thin`である

### 19.9 未使用枠

- 出力対象日が奇数件の場合、最後の右側枠が完全な空白である
- 未使用枠に値、セル結合および罫線がない
- 授業がない出力対象日は空の日付マトリクスとして生成される

### 19.10 教師休み注記

- 終日休みが教師名だけで出力される
- 時限指定休みが教師名と直右セルの時限表記で出力される
- 2時限連続は丸付き数字の連結となる
- 3時限以上連続は範囲表記となる
- 各校舎の最初の教室列から隙間なく配置される
- 教師休み注記セルに表本体の罫線が付かない
- 教師休み注記セルのフォント、文字サイズおよび行高が時間割本体と一致する

## 20. テスト方針

### 20.1 単体テスト

以下をテストする。

- 日付順整列
- 左右の開始列計算
- 各日付の開始行計算
- 校舎結合範囲計算
- 時限行計算
- 日付表示形式
- 曜日生成
- 丸数字変換
- 時限表示文字列生成
- 授業の`日付×時限×教室`展開
- 重複授業検知
- 未使用枠を生成しないこと

### 20.2 Excel構造テスト

`openpyxl`で生成ファイルを読み直し、以下を検証する。

- Worksheet構成
- セル値
- 結合範囲
- 罫線種別
- 日付数値書式
- 未使用枠の空白
- 外部リンクが存在しないこと

### 20.3 Golden Masterテスト

少数の日付、校舎、教室、授業を持つ固定入力からExcelを生成し、期待する構造と比較する。

バイナリファイル全体の一致ではなく、以下を比較対象とする。

- セル値
- 結合範囲
- 罫線
- 数値書式
- Worksheet名
- 対象セル範囲

Excel内部の生成日時やライブラリ依存メタデータは比較対象外とする。

### 20.4 最低限のテストケース

| ケース | 内容 |
|---|---|
| 1日 | 左側だけ生成され、右側が完全な空白 |
| 2日 | 左右に1日ずつ生成 |
| 3日 | 2行目左まで生成し、右側が完全な空白 |
| 4日 | 2行×2列相当の配置 |
| 5日以上 | 2列の行優先配置が継続 |
| 授業なし日 | 日付・曜日・ヘッダだけ生成され授業セルは空欄 |
| 複数校舎 | 校舎境界が普通線 |
| 複数教室 | 校舎内教室境界が点線相当 |
| 重複授業 | 出力前エラー |
| 時刻変更 | 入力Excelの変更が表示へ反映 |

## 21. 実装上の禁止事項

- 日付ごとのセル番地をハードコードしない
- 校舎数または教室数をコードへ固定しない
- 校舎順、教室順を名称順から推測しない
- 時限の開始・終了時刻をコードへ固定しない
- Excel固有処理をServiceへ置かない
- `openpyxl`をModelまたはServiceからimportしない
- 未使用枠へ空マトリクスを生成しない
- 複数授業を改行または区切り文字で1教室枠へ連結しない
- 休館日等の文字を出力処理で推測して追加しない
- 参照資料の外部リンク数式を再利用しない
- 既存の一覧形式出力を本契約の完成形として扱わない
